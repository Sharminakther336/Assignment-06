# FitLog

FitLog is a workout library and workout planning website. Users can explore different workouts, see workout details, add workouts to their plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Local Storage

## Key Features

- Users can browse different workouts from the workout library.
- Users can view workout details including equipment, duration, calories, and instructions.
- Users can add workouts to Today's Plan.
- Users can save workouts for later.
- Users can see their total exercises, workout minutes, and calories in My Plan.
